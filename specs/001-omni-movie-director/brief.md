# Clarity Brief: 001-omni-movie-director

## 1. Outcome & Vision
Upgrade Ashik Kay's 2025 Opal/VidAgent ("Beyond the Single Prompt") architecture into the industrial 2026 `omni-movie-director` creative suite. The system combines:
1. Portable Agent Skills (`gemini-omni-prompting` and `omni-movie-director`) usable across Google Antigravity, Gemini Code Assist, Cursor, and Claude Code.
2. A production-grade Google ADK 2.0 multi-agent architecture (`SequentialAgent` + `ParallelAgent` / `Workflow`) that takes a raw user prompt or brand brief and orchestrates an immutable Master Production Bible (SSOT 2.0), deterministic 3-Anchor Nano Banana pre-visualization, parallel Gemini Omni scene prompts with Seedance kinetic physics and CRAFT camera telemetry, dual-layer sonic design, and self-contained cinema darkroom HTML storyboards.
3. Dual-Mode execution: Mode A (Parallel Multi-Scene Montage) and Mode B (Continuous +10s Scene Extension Chain up to 40s).

## 2. Non-Goals
- **No Monolithic Single-Prompt Execution**: Never collapse character design, environment layout, audio cues, and camera motion into a single un-grounded text prompt.
- **No Deprecated Model Usage**: Explicitly forbid legacy Gemini 1.5, 3.1, or Veo 3.1 models. Active generation is restricted strictly to 2026 tier models (`gemini-4-argon`, `gemini-3.8-flash`, `gemini-3-pro-image`, `gemini-omni-1.1-flash-preview`).
- **No Video-Before-Storyboard**: Live video synthesis must never occur without deterministic visual grounding from Nano Banana concept art anchors.
- **No Heavy External Server Dependencies for Storyboards**: Storyboard treatments must compile into self-contained HTML/CSS/JS files viewable in any local browser without node daemons.

## 3. User Stories
- **US-1 (Creative Director)**: As a commercial director or agency lead, I want to provide a brand prompt or deck and receive an intake interview with at most 5 high-leverage questions, followed by an immutable Master Production Bible detailing characters, environments, CRAFT camera setups, and sonic curves.
- **US-2 (Storyboard Artist / Concept Designer)**: As a production designer, I want deterministic 3-anchor concept art (3-panel character turnaround on 18% gray, zero-character master environment plate, and shot-by-shot $t=0.0s$ keyframes) generated by Nano Banana Pro (`gemini-3-pro-image`) that enforce Gemini Omni's 3-reference ceiling (`<image_1>`, `<image_2>`, `<image_3>`) with strict inclusion/exclusion rules.
- **US-3 (Video & Sound Prompt Engineer)**: As a prompt director, I want to synthesize clean, natural prose prompts for Gemini Omni that enforce Seedance 5-part kinetic contact chains, 1.0x real-time speed locks, CRAFT camera routing, diegetic foley, and a synchronized Master BGM score.
- **US-4 (Producer & Client Reviewer)**: As a producer, I want an interactive, darkroom cinema HTML treatment (`storyboard_preview.html`) with audio playback, shot scrubbers, CRAFT telemetry HUD, and one-click prompt copy buttons, plus a complete `production_bundle.json`.
- **US-5 (Pipeline Developer / FDE)**: As a pipeline developer, I want a modular Python package (`omni_director`) powered by ADK 2.0 and `uv` that supports `--dry-run` (instant synthetic mock), `--hybrid` (default: Bible + Nano Banana + Omni prompts + HTML preview), and `--render-video` (live Gemini Omni video/audio synthesis).

## 4. Observable User Flows
1. **Flow A (Developer In-Editor / Agent Skill Workflow)**:
   - User or orchestrator invokes `skills/omni-movie-director/SKILL.md`.
   - Agent interrogates prompt with 5 high-leverage intake questions (or applies smart defaults).
   - Agent generates Master Production Bible (SSOT 2.0) in JSON.
   - Agent drafts Nano Banana prompts for 3 Visual Anchors.
   - Agent synthesizes Gemini Omni natural-prose scene prompts following `skills/gemini-omni-prompting/SKILL.md`.
   - Agent outputs compiled `storyboard_preview.html` and `production_bundle.json`.
2. **Flow B (Headless CLI / ADK 2.0 Pipeline Workflow)**:
   - User runs `omni run --input brief.json --mode hybrid --output ./dist/`.
   - `IntakeAndResearchAgent` parses brief and grounds with Google Search.
   - `CreativeDirectorAgent` (`gemini-4-argon`) emits `ProductionBible`.
   - `VisualBibleGeneratorAgent` & `StoryboardParallelAgent` generate PNG visual anchors via Nano Banana (`gemini-3-pro-image`).
   - `ScenePromptFanOutAgent` (`gemini-3.8-flash`) synthesizes scene prompts concurrently with `BGMComposerAgent`.
   - `StoryboardHTMLCompilerAgent` compiles standalone `storyboard_preview.html` and exports `production_bundle.json`.
   - (Optional) `OptionalOmniVideoRenderAgent` calls `gemini-omni-1.1-flash-preview` in parallel or continuous extension mode.

## 5. Architectural Rulings & Hard Invariants
- **Strict Model Hierarchy**:
  * Lead Creative Director: `gemini-4-argon`
  * Fast Scene & Prompt Specialists: `gemini-3.8-flash`
  * Visual Concept Art & Storyboarding: `gemini-3-pro-image` (Nano Banana Pro)
  * Video + Multimodal Synchronized Audio: `gemini-omni-1.1-flash-preview`
  * *Zero legacy 3.1 models* permitted in active pipelines.
- **Execution Topology**:
  * Default pipeline mode: `--hybrid` (generates Bible, Nano Banana storyboards, Omni prompts, and HTML treatment; zero wasted video quota).
  * Video execution: opt-in via `--render-video` supporting Mode A (Parallel Reference-to-Video) and Mode B (Continuous +10s Scene Extension Chain via `previous_interaction_id`).
- **Prompt Engineering Law**:
  * No internal markdown headers inside Gemini Omni generation prompts (avoids on-screen text hallucinations).
  * Real-time 1.0x playback speed lock and gravity invariants mandatory on all Regime 2 kinetic prompts.
  * Ceiling of exactly $\le 3$ reference images (`<image_1>`, `<image_2>`, `<image_3>`) with explicit "One Job Per Reference" inclusion/exclusion clauses.
- **Target Repository & Distribution**:
  * GitHub: `spiralspectra/omniskill`
  * Package manager: `uv` (PEP 621 compliant `pyproject.toml`).

## 6. Complexity Assessment
- **Route**: `dedicated`
- **Size**: `medium` (multi-component spec, 2 core portable skills, reference libraries, and ADK 2.0 architecture schemas).
- **Risk Level**: Low-Medium (mitigated by strict Pydantic v2 schemas and deterministic mock testing).
